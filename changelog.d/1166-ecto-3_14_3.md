### Security
- **`ecto` 3.14.0 → 3.14.3 (CVE-2026-118391).** A HIGH advisory against Ecto 3.4.0 up to
  3.14.2: a query that interpolates a JSON path (`json_extract_path/2`, `field[^key]`) or a
  `splice/1` list added a query cache entry for each distinct key or list length, and nothing
  freed them, so request data could grow memory without bound. 3.14.3 stops caching those
  queries and the ones that use `constant/1`. Cinder's queries use none of these forms. The
  advisory also failed the required `mix hex.audit` CI check on every PR.
