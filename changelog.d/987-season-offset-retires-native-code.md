### Fixed
- **A saved season offset stops a release named by an episode's TMDB code from reaching that episode (#987).** When an offset makes TMDB's S02E05 the scene S03E05, a TV season's search no longer reads a release named "S02E05" as that episode, where the sweep could grab it before, unless a mapping made by hand names "S02E05" for that episode. On a standard series the sweep and the upgrade sweep skip such a release, the sweep also skips the season's whole-season pack, and the manual search panel shows the release as rejected and refuses to grab it. On an anime series the release no longer covers that episode, nor any other episode through a mapping a provider sync derived, while a release named "S03E05" still covers it. A code given to one episode by hand leaves that episode's TMDB code in use. On a standard series, a release found under another season's numbering, named by a code the offset took from its TMDB episode, can now go to the episode a hand-made TVDB-aired mapping names for that code, where Cinder could refuse it as ambiguous before.
