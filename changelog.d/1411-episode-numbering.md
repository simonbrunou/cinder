### Internal
- **The standard and anime searches read episode numbering one way (#1411).** They read which
  episode a code names through `Cinder.Catalog.EpisodeNumbering`, which owns the scheme bridge, a
  vetted mapping's precedence over a native code and a saved offset's retirement of one. The
  imports and the reservation still apply neither of the last two. Searches pick the same
  episodes as before.
