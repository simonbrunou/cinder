### Security
- **`idna` 7.1.0 → 8.0.0 (CVE-2026-117678), with `swoosh` 1.26.3 → 1.30.0.** A MEDIUM advisory
  against `idna` from 0.5.0 up to, but not including, 8.0.0: it decoded a punycode label before
  checking the 63-octet label limit, so a long `xn--` label cost super-linear CPU time. 8.0.0
  rejects an over-long label before decoding it. When Cinder sends mail over SMTP, Swoosh passes
  the domain of each From and To address that holds a single `@` through `idna`. Swoosh 1.26.3
  refused `idna` 8, so Swoosh moves to 1.30.0, which allows it. The advisory also failed the
  required `mix hex.audit` CI check on every PR whose `mix.lock` held `idna` 7.1.0.
