### Added
- **A Plex sign-in health row, and an hourly check that notifies you when plex.tv stops listing your Plex server (#1208).** While Plex is configured, `/dashboard` shows a "Plex sign-in (owner account)" row, and the media server group in `/settings` has a Test button for it. The check asks plex.tv, with the Plex token in your media server settings, whether that account still lists your Plex server, which Plex sign-in needs. It does not try a sign-in or show what a shared user sees. Cinder also runs the check about 5 minutes after it starts and then every hour. It sends one notification (to Discord and the webhook when you set them up, and to the log; never by email) when the check starts failing, and one when it passes again. A token plex.tv rejects, a server plex.tv no longer lists, or an answer Cinder cannot read is reported on the first failing check; any other error, such as a timeout, only on the second failing check in a row. Cinder keeps no record of a reported failure across a restart, so a failure still going on is reported again after one.
