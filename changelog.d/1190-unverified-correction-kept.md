### Fixed
- **A subtitle correction whose file fails to open right after it was written, yet Cinder reads it back as the correction, keeps its record (#1190).** Right after a correction writes a subtitle file, Cinder opens the file to check that it is still the file Cinder wrote. When that open failed, Cinder took the file as replaced by someone else: the correction dropped its record although the file held the corrected subtitle, and the next manual correction of that subtitle failed as changed outside Cinder. Cinder now reads the file back when only that open fails. When the read works and the file holds the corrected subtitle, the correction keeps its record.
