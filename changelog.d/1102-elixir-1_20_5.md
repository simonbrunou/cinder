### Security
- **Elixir 1.20.4 → 1.20.5 in the container image (CVE-2026-109821).** The release ships the
  Elixir it is built with. 1.20.5's `URI.parse/1` drops a port above 65535 from the URL it
  parses. Cinder still refuses a redirect, or a download URL on the indexer's own host, whose port
  is above 65535: with 1.20.5 alone it read that port as 443 or 80 (#1102). The image's Debian
  base moves to trixie-20261027, the one hexpm/elixir builds 1.20.5 on.
