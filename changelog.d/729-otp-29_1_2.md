### Security
- **Erlang/OTP 29.1.1 → 29.1.2 in the container image (CVE-2026-94200 and four more).** The
  release ships the OTP runtime it is built with. 29.1.2 fixes a TLS 1.3 session ticket that
  crashed a client's ticket store, TLS 1.2 session resumption across SNI names on a server,
  `httpc` sending URL credentials to a cross-origin redirect and an `erl_tar` infinite loop on a
  crafted archive. It also closes a gap in the CVE-2026-42789 fix: certificate path validation
  still accepted an X.509 v1 or v2 certificate as a CA. Cinder's outbound HTTPS requests run on
  OTP's `ssl`, so the certificate check covers them.
