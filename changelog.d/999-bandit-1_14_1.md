### Security
- **`bandit` 1.14.0 → 1.14.1 (CVE-2026-116078).** A HIGH advisory against Bandit 1.14.0: its
  HTTP/2 body reader kept every DATA frame as its own list element, so a client sending a
  request body as 1-byte frames could tie up many times the body's size in server memory on any
  route that reads the body. 1.14.1 fixes it. It also rejects an HTTP/2 request whose `host`
  header does not match `:authority`, drops connection-specific headers from HTTP/2 responses,
  and trims trailing whitespace from HTTP/1 header values. The advisory also failed the required
  `mix hex.audit` CI check on every PR.
