### Changed
- **A book held on a blocked file names that file in one sentence (#913).** On the book's page,
  in the requester's email and in the Discord message, such a hold now reads as one sentence, for
  example "The download holds a blocked file (setup.exe) and no book.", in the same language as
  the rest of that page or message. In English it used to read "The download holds a blocked
  file, such as a program, and no book. Details: download contains setup.exe", and the "download
  contains setup.exe" part stayed English in every language. The book's "Held books" row on
  `/activity` reads the same sentence. Books held before the update read the new way too.
